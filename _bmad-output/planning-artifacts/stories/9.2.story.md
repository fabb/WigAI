# Story 9.2: Device Chain Editing Tools

**Epic:** [Epic 9: Project Editing](../prd/epic-9.md)

**User Story:**

*   As an AI agent, I want to insert Bitwig built-in devices by name and plugins by CLAP or VST3 id, and copy, move, bypass and delete devices, so I can build signal chains.

**Acceptance Criteria:**

*   MCP tools `list_bitwig_devices`, `insert_device`, `copy_device`, `move_device`, `delete_device`, `set_device_enabled` and `set_device_window_open` are implemented and registered.
*   `list_bitwig_devices` returns the names of Bitwig's built-in devices known to the extension.
*   `insert_device` takes exactly one of:
    *   `bitwig_device`: a built-in device name, matched case-insensitively (e.g. `EQ+`, `Vocoder`, `Reverb`); unknown names return `DEVICE_NOT_FOUND`.
    *   `clap_id`: e.g. `org.surge-synth-team.surge-xt`.
    *   `vst3_id`: the plugin's VST3 class id.
    *   None given → `MISSING_REQUIRED_PARAMETER`.
*   Insertion position: `position` = `start` | `end` (default `end`), or `after_device_index` to insert directly after an existing device.
*   `copy_device` and `move_device` take a source (`from_track_index`/`from_track_name`, `from_device_index`) and a destination (`to_track_index`/`to_track_name` plus the same position options). Copies keep all device settings.
*   `delete_device` removes a device; `set_device_enabled` bypasses (`false`) or enables (`true`) it; `set_device_window_open` opens or closes a plugin window.
*   Mutating tools return the resulting device chain (`index`, `name`, `enabled`) of the affected track.
*   `api-reference.md` documents all seven tools.
*   Unit tests cover insertion by name/CLAP id, position resolution, copy vs. move, unknown and missing device ids, and missing devices.

### Implementation Notes

*   Built-in device UUIDs are bundled in `src/main/resources/bitwig-devices.txt` (`Name$uuid` per line), taken from DrivenByMoss's device lists (LGPL-3.0, attributed in the file), and inserted with `InsertionPoint.insertBitwigDevice(UUID)`.
*   Copy and move use `InsertionPoint.copyDevices` / `moveDevices` on `Track.startOfDeviceChainInsertionPoint()`, `endOfDeviceChainInsertionPoint()` or `Device.afterDeviceInsertionPoint()`.
