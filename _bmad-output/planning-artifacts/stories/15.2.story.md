# Story 15.2: Streaming Changes

**Epic:** [Epic 15: Following the User](../prd/epic-15.md)

**User Story:**

*   As an AI agent, I want to receive changes as notifications while a call runs.

**Acceptance Criteria:**

*   `watch` runs for `duration_ms` and sends each change as an MCP progress notification (when the call has a progress token) and as a logging notification (logger `wigai.events`), then returns all of them.
*   Server instructions sent on initialize tell agents how to start, follow changes, and what the API cannot do; `docs/AGENT-GUIDE.md` has the full guide.
*   `api-reference.md` documents `watch`.

### Implementation Notes

*   Verified on the raw HTTP stream: notifications arrive as the changes happen, before the result.
