# Story 13.5: Arranger Clips

**Epic:** [Epic 13: Arrangement, Scenes, Clips and Notes](../prd/epic-13.md)

**User Story:**

*   As an AI agent, I want to edit the arranger clip the user selected.

**Acceptance Criteria:**

*   `read_notes`, `edit_notes`, `set_clip` and `transform_clip` take `arranger: true` to work on the clip selected in the arranger; `write_arranger_notes` writes notes into it.
*   With nothing selected, they return `CLIP_NOT_FOUND` explaining that the user must select a clip.
*   `api-reference.md` documents `write_arranger_notes`.

### Implementation Notes

*   Uses `host.createArrangerCursorClip`.
