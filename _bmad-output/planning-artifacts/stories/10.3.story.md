# Story 10.3: Drum Machine Pads and Layer Mixers

**Epic:** [Epic 10: Device Chains, Presets and Containers](../prd/epic-10.md)

**User Story:**

*   As an AI agent, I want to set up Drum Machine pads and balance the layers of a layer device.

**Acceptance Criteria:**

*   `list_drum_pads` lists pads by MIDI key with note name, mixer state and devices; empty pads only with `include_empty`.
*   `set_drum_pad` and `set_layer` set name, volume (raw or exact `volume_db`), pan, mute, solo, activation.
*   `insert_into_drum_pad` adds a device, plugin, preset, or a sample file (Bitwig creates a Sampler).
*   `clear_drum_pads` unmutes and/or unsolos every pad.
*   `api-reference.md` documents `list_drum_pads`, `set_drum_pad`, `insert_into_drum_pad`, `clear_drum_pads`, `list_layers`, `set_layer`.

### Implementation Notes

*   `DrumPadBank` of 128 with `scrollPosition` 0, so pad index = MIDI key; pads and layers are `Channel`s, so the track volume search is reused for `volume_db`.
