# Story 9.4: Clips and Notes

**Epic:** [Epic 9: Project Editing](../prd/epic-9.md)

**User Story:**

*   As an AI agent, I want to import audio and MIDI files into clip slots, create empty clips and write notes into them, so I can supply musical material.

**Acceptance Criteria:**

*   MCP tools `insert_file`, `create_clip`, `delete_clip` and `write_notes` are implemented and registered.
*   `insert_file` takes an absolute `path` (must exist, else `INVALID_PARAMETER`) and a track:
    *   with `slot_index`: the file is inserted into that launcher slot (`ClipLauncherSlot.replaceInsertionPoint().insertFile`); the result reports whether the slot now has content.
    *   without `slot_index`: Bitwig inserts it after the track (`Track.afterTrackInsertionPoint().insertFile`), creating a new track.
*   `create_clip` creates an empty launcher clip of `length_beats` in an empty slot; an occupied slot returns `INVALID_PARAMETER`.
*   `delete_clip` deletes the clip in a slot.
*   `write_notes` writes `notes` (`start` and `duration` in beats from the clip start, `pitch` 0–127, `velocity` 1–127, default 100) into an existing clip on a 1/64-beat grid. `clear_first: true` removes existing notes first. An empty slot returns `CLIP_NOT_FOUND`.
*   `api-reference.md` documents all four tools.
*   Unit tests cover missing files and note argument mapping (default velocity).

### Implementation Notes

*   Notes are written through a launcher cursor clip created at init on the private edit cursor track (`createLauncherCursorClip(16384, 128)`, step size 1/16 beat). The target slot is selected so the cursor clip follows it.
*   The Controller API cannot place clips on the arranger timeline; that is out of scope.
