# Story 10.2: Presets and Bitwig's Browser

**Epic:** [Epic 10: Device Chains, Presets and Containers](../prd/epic-10.md)

**User Story:**

*   As an AI agent, I want to load presets and search Bitwig's library, so I can start from a designed sound.

**Acceptance Criteria:**

*   `list_presets` indexes every `.bwpreset` under the installed packages and the user library and searches name, collection, device and category (all words must match).
*   `insert_device` and `replace_device` take `preset_file`; `replace_device` swaps a device, plugin or preset in place.
*   `browser_open` opens Bitwig's popup browser at an insertion point (`replace`, `after`, `before`, `start`, `end`); `browser_state` shows content types, each filter column's selection and a page of results; `browser_filter` sets the content type and filters by column and item name; `browser_commit` loads a result by name or index and reports what was loaded; `browser_cancel` closes it.
*   Device lists report each device's loaded preset.
*   `api-reference.md` documents `list_presets`, `replace_device`, `browser_open`, `browser_state`, `browser_filter`, `browser_commit`, `browser_cancel`.

### Implementation Notes

*   Presets load through `InsertionPoint.insertFile`.
*   The browser is `host.createPopupBrowser()` with an item bank of 64 per filter column and for the results; columns and results are paged with `scrollPosition`.
*   Opened in `replace` mode on a device, Bitwig filters the browser to that device's presets.
