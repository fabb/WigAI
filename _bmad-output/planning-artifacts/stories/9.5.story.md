# Story 9.5: Transport Settings and Application Actions

**Epic:** [Epic 9: Project Editing](../prd/epic-9.md)

**User Story:**

*   As an AI agent, I want to set tempo, play position, loop, metronome, record and overdub, list and invoke Bitwig application actions, and undo/redo, so I can reach functionality that has no dedicated tool and recover from mistakes.

**Acceptance Criteria:**

*   MCP tools `set_transport`, `list_actions`, `invoke_action`, `undo` and `redo` are implemented and registered.
*   `set_transport` changes only given fields: `tempo_bpm` (set via the tempo's raw value), `position_beats`, `loop`, `metronome`, `record`, `overdub`. It returns the resulting transport state.
*   `list_actions` returns `id`, `name` and `category` for every Bitwig application action, optionally filtered by a case-insensitive substring of id, name or category.
*   `invoke_action` runs an action by `id`; an unknown id returns `INVALID_PARAMETER`.
*   `undo` and `redo` call `Application.undo()` / `redo()`.
*   `api-reference.md` documents all five tools.
*   Unit tests cover action filtering and unknown action ids.
