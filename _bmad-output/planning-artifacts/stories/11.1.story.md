# Story 11.1: Installed Devices and Plugins

**Epic:** [Epic 11: Device Knowledge](../prd/epic-11.md)

**User Story:**

*   As an AI agent, I want to search everything installed, built-in and plugin, so I know what I can use.

**Acceptance Criteria:**

*   Built-in devices are read from Bitwig's library (`<installationRoot>/Library/device-settings`), so every device of the running version is listed and insertable; a copy generated from it is bundled.
*   CLAP, VST3 and VST2 plugins are read from Bitwig's plugin metadata cache (`~/.BitwigStudio/cache/clap-metadata-N`, `vst3-metadata-N`, `vst-metadata-N`) with id, vendor, category, version and features, without loading any plugin.
*   Results carry the id that `insert_device` takes (`clap_id`, `vst3_id`, `vst2_id`).
*   LV2 plugins usable through Carla can be added by `scripts/device_catalog.py inventory`.
*   `api-reference.md` documents `list_installed_devices`.

### Implementation Notes

*   The cache is Bitwig's undocumented tagged format; `PluginCache` reads only known tags (category 0x3e3, name 0x3e4, vendor 0x3e6, CLAP id 0x2ec4, VST id 0x3e2) and skips everything else.
