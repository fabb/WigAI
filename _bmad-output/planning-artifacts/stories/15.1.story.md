# Story 15.1: Event Log

**Epic:** [Epic 15: Following the User](../prd/epic-15.md)

**User Story:**

*   As an AI agent, I want to get every change since I last looked, or wait for the next one.

**Acceptance Criteria:**

*   Changes are recorded with increasing sequence numbers: transport (play, record, loop, metronome, tempo, time signature), project (name, engine), track (name, mute, solo, arm, volume, pan, added/removed), clip (launcher playback state, clips created/deleted), selection (the user's track, device, preset) and parameter (the selected device's remote controls).
*   `get_events` without `since_seq` returns a starting point; with it, the events after it, optionally filtered by type and waiting up to `wait_ms` for the first one.
*   Rapid changes to one thing within 250 ms are merged into the latest; a full buffer (2000) reports `missed_events`.
*   `api-reference.md` documents `get_events`.

### Implementation Notes

*   Observers are registered at init; the burst of initial values is ignored for 2 s.
